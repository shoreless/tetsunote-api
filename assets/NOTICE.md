# Atlas assets

`vendor/` contains Three.js 0.180.0 and OrbitControls, distributed under the MIT license in `vendor/THREE-LICENSE.txt`. Regenerate with `npm ci && npm run vendor`.

`japan.geojson` contains Japan's polygons extracted without geometric modification from Natural Earth's 1:50m Admin 0 Countries dataset:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/
The coastline is a visual reference, not an authoritative boundary map.
